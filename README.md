# Nebbia

A one-page site for an invented electronic music festival in the old Bovisa gasworks in Milan, 22–24 January 2027.
Portfolio demo: the festival, artists and prices are made up; the place, its history and the photographs are real.

**Live:** https://yehorss.github.io/nebbia/

- Line-up for three nights; tap a name to see the stage and time and add the set to your plan.
- **My plan:** a stage × time grid (a list on phones). Pick sets, see which ones clash, how far you walk
  between stages and how many minutes of each set that costs. The plan stays in the browser and can be shared as a link.
- The place: real facts about la Goccia and the gasholders, a site diagram, how to get there.
- Italian and English, own scrollbar, responsive photos (960/1600/2560 WebP).

## Run

```
npm install
npm run dev      # http://localhost:5197/nebbia/
npm test
npm run build
```

`npm run photos` rebuilds the WebP sizes from full-resolution originals (not in the repo).

Photos from Wikimedia Commons; authors and licences are listed in the page footer.
